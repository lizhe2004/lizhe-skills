# 单向流式语音合成错误码

来源：火山引擎「语音合成接口常见错误码」（https://docs.volcengine.com/docs/6561/2534853?lang=zh），这里只整理本 skill 用到的单向流式 HTTP 语音合成部分；音频生成、声音复刻接口的错误码请查看原页面。

- 失败时 HTTP 状态码非 200，响应体带 `code`（int）和 `message`（string）。
- `5` 开头的 8 位码是服务端错误，`4` 开头是请求方问题。
- 反馈问题时提供响应头里的 Logid（脚本报错时会打印 `logid`）。

| code | message | 原因 | 处理 | 脚本是否重试 |
| --- | --- | --- | --- | --- |
| 45000000 | payload unmarshal: … unmarshal request | 请求体不是合法 JSON | 修正 payload 格式 | 否 |
| 45000000 | quota exceeded for types: concurrency | 超并发 | 降低并发 / 错峰；可在控制台增购并发 | 是 |
| 45000000 | single request size too large | 请求体过大 | 缩短文本或拆分请求 | 否 |
| 45000001 | [Invalid argument] EmptyRequest | 缺少 `req_params` | 补上 `req_params` | 否 |
| 45000001 | [Invalid argument] speaker not found | 音色参数错误 | 检查 `speaker` | 否 |
| 45000001 | [Invalid argument] InvalidModel | `model` 非法 | 只对声音复刻 2.0 生效，取值 `seed-tts-2.0-standard` / `seed-tts-2.0-expressive` | 否 |
| 45000001 | [Invalid argument] InvalidDialect | `explicit_dialect` 非法 | 按 API 参考修正 | 否 |
| 45000010 | Invalid X-Api-Key | API Key 无效（HTTP 401，实测，官方表未列出） | 使用豆包语音控制台「API Key 管理」里的 Key | 否 |
| 45002000 | TTS invalid speaker | `speaker` 为空 | 填写音色 ID | 否 |
| 45002001 | No readable text! | 没有可读文本 | 检查文本 | 否 |
| 55000000 | 服务端内部 error | 服务端通用错误 | 稍后重试 | 是 |
| 55000000 | Request timeout: connect downstream service timeout | 网关连接下游超时（服务暂不可用或网络抖动） | 稍后重试；持续出现联系技术支持 | 是 |
| 55000000 | Request timeout: synthesis processing timeout | 合成超时，多因文本过长或负载高 | 缩短单次文本或错峰 | 是 |
| 55000000 | resource ID is mismatched with speaker related resource | 该资源下没有这个音色 | 依次检查：服务是否开通、音色 ID 拼写、复刻音色是否过期、是否有该音色权限 | **否**（配置问题，重试无效） |

`Request timeout: client send timeout` 只出现在 WebSocket 接口，本 skill 用的 HTTP 接口不会遇到。
