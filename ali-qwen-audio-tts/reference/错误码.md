# Qwen-Audio-TTS 常见错误码

依据阿里云百炼「错误码」文档（https://docs.bailian.console.aliyun.com/zh/model-studio/error-code）整理，只保留语音合成、鉴权、计费、限流相关的部分。完整列表和最新说明以原页面为准。

- 失败时响应体带 `code`、`message` 和 `request_id`（OpenAI 兼容接口为 `error.code` / `error.message` / `error.id`）。反馈问题时提供 `request_id`。
- 脚本会对「是否重试」做判断：只重试限流和服务端临时故障；计费、配额、订购类错误即使是 429 也不重试。

## 计费与配额（不重试）

| HTTP | code | 含义 | 处理 |
| --- | --- | --- | --- |
| 403 | AllocationQuota.FreeTierOnly | 免费额度用尽：开启了「免费额度用完即停」，或新账号未实名认证 | 关闭开关（之后按量计费）或认证充值；关闭后仍报错可重置 API Key。控制台额度显示按分钟更新 |
| 400 | Arrearage | 账户欠费 | 充值 |
| 400 | Throttling.AllocationQuota | 复刻音色数量达账号上限 | 删除不用的复刻音色 |
| 429 | Throttling.AllocationQuota / insufficient_quota | 调用配额超限 | 调高配额或检查套餐、账单 |
| 429 | CommodityNotPurchased | 业务空间未订购 | 先订购 |
| 429 | PrepaidBillOverdue / PostpaidBillOverdue | 账单到期或推理商品失效 | 续费 |
| 429 | BudgetLimitExceeded | 预算管理中的预算用尽且开启了「达预算即停」 | 提高预算或关闭开关；停机有延迟，延迟期间仍计费 |

## 限流与服务端（自动重试）

| HTTP | code | 含义 |
| --- | --- | --- |
| 429 | Throttling / Throttling.RateQuota / Throttling.BurstRate | 请求频率或突发流量超限 |
| 429 | Throttling.Concurrency / ServiceOverloaded / ResourceExhausted | 并发超限或系统容量不足 |
| 500 | InternalError / SystemError / RequestTimeOut | 服务端内部错误或超时 |
| 503 | ServiceUnavailable / ModelUnavailable | 服务或模型暂不可用 |

## 语音合成参数（不重试）

| message | 含义 | 处理 |
| --- | --- | --- |
| `[cosyvoice:]Engine error [411]` / `Engine return error code: 411` | 音色与模型不匹配或不存在（实测）；或该模型只支持复刻音色却传了默认音色 | 在 `reference/voices/<model>.csv` 核对 voice |
| `[tts:]Engine return error code: 418` | 音色不正确，或模型与音色版本不匹配（不同版本不能混用） | 同上；复刻音色确认状态正常且归属当前账号 |
| `[tts:]Engine return error code: 428` | `instruction` 超长，或格式、语言不被该模型/音色支持 | 缩短或改写指令 |
| `Request voice is invalid!` | 未设置音色 | 检查 `--voice` |
| `DataInspectionFailed` / `inappropriate content` | 文本未通过内容安全审核 | 修改文本 |

## 鉴权与权限（不重试）

| HTTP | code / message | 含义 |
| --- | --- | --- |
| 401 | InvalidApiKey（Invalid API-key provided） | Key 无效，或与业务空间不在同一地域 |
| 403 | Access denied by API-Key restrictions | Key 被限定了可调用的模型范围 |
| 403 | AccessDenied.Unpurchased / Model.AccessDenied | 模型未开通或无权使用 |
| 403 / 404 | Workspace.AccessDenied / WorkSpaceNotFound | 业务空间不存在或 Key 不属于该空间 |
