# Sambert 使用指南

## 选音色

Sambert 是模型，`sambert-...-v1` 是它提供的音色 ID。通过 `--voice` 选择音色，例如 `sambert-beth-v1`、`sambert-betty-v1` 和 `sambert-zhiyue-v1`。日常选音色只查 [sambert.csv](../voices/sambert.csv)，其中有语言、适用场景、声线特质、默认采样率、时间戳支持和参考免费额度。优先使用音色的默认采样率；升采样不会提高原始音质。中文配音可从知厨（新闻播报）、知祥（磁性解说）、知伦（悬疑解说）、知飞（激昂解说）等音色试听选择；不要把 Qwen 音色 ID 传给 Sambert。

Sambert 仅支持北京地域，API Key 和业务空间 ID 都须属于北京。脚本要求 Python 3.9 或更高版本，并依赖 `dashscope` Python SDK。设置 `DASHSCOPE_API_KEY` 与 `ALI_WORKSPACE_ID` 后，用 [sambert_tts.py](../../scripts/sambert_tts.py) 调用；脚本通过 SDK 同步调用返回完整音频。不要把 API Key 写入文件或输出。

## 参数与输出

- `--voice` 必填，如 `sambert-zhichu-v1`；从 [sambert.csv](../voices/sambert.csv) 选择。脚本会把它转换为 SDK 所需的底层请求字段。
- `--endpoint auto` 是默认值：先使用业务空间专属 WebSocket 域名；仅在 DNS 连接失败时自动改用旧域名 `dashscope.aliyuncs.com`。也可固定使用 `--endpoint workspace` 或 `--endpoint legacy`。脚本始终将 `ALI_WORKSPACE_ID` 显式传给 SDK。
- `--text` 必填，最多 10000 字符。文档说明支持 SSML；需使用时先核对该模型的实际效果。
- `--format` 为 `wav`（默认）、`mp3` 或 `pcm`。`--output` 扩展名必须匹配格式。
- `--sample-rate` 可省略；脚本对文档中标为 48 kHz 的九个模型默认用 48000，其余默认 16000。`--volume` 为 0–100，`--rate` 和 `--pitch` 为 0.5–2.0。
- `--timestamps` 会开启字级时间戳，保存以毫秒为单位的 `sentences`。`--phoneme-timestamps` 需与 `--timestamps` 同用，在各 `words[].phonemes` 中保存音素时间戳。先查模型列表的时间戳支持列。
- `--metadata` 可保存本地请求摘要与音频字节数，不含密钥。

例如：

```bash
python3 scripts/sambert_tts.py \
  --voice sambert-zhixiang-v1 \
  --text '这里是完整的待合成文本。' \
  --format mp3 --output ./narration.mp3 \
  --timestamps ./narration.timestamps.json --phoneme-timestamps
```

Sambert 的语音输出可分块到达，但文本须在 `run-task` 中一次提交；没有 `continue-task` 或 `finish-task`。脚本使用 SDK 同步调用，所以适合需要完整文件的场景。若需要边生成边播放，才读 [SDK 单向流式调用](sdk接入.md)的回调；若要手写或排查原始 WebSocket 客户端，才读 [WebSocket 接入和事件](接入api.md)。不要把每块 WAV 当独立文件处理。

调用前留意按字符计费和模型免费额度。只在用户明确要合成时发起请求；批量任务若额度或费用不明确，先确认。出现 `AllocationQuota.FreeTierOnly` 表示免费额度已用完，服务端没有合成；到百炼控制台完成付费设置，或关闭「仅使用免费额度」后重试，后者会产生按量费用。保留命令输出中的 `request_id` 以便排障。
